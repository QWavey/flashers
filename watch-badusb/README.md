# ESP-Watch-BadUSB WebFlasher

BadUSB firmware for the Waveshare ESP32-S3 Touch-AMOLED 2.06" watch — flashed straight from the browser.

**Live:** https://qwavey.github.io/flashers/watch-badusb/
**Firmware source:** https://github.com/QWavey/ESP-Watch-BadUSB
**Hub:** https://qwavey.github.io/flashers/ *(also in this repo, one level up)*

This writes the ESP-Watch-BadUSB firmware onto the watch over USB with WebSerial. It replaces whatever firmware is on the board now — including the stock Xiaozhi demo.

This is a static web project generated by
[FlasherForge](https://github.com/QWavey). It flashes firmware to the device
**directly from the browser** over ESP32 (WebSerial + esptool-js) — no toolchain, no
command line. Everything runs locally in the page; nothing is uploaded.

## Run it

It is a static site. Serve the folder over HTTP (WebSerial/WebUSB need a secure
context — `http://localhost` counts) and open it in Chrome or Edge:

```bash
cd watch-badusb
python -m http.server 8000
# then open http://localhost:8000
```

Or publish the folder to GitHub Pages / any static host over HTTPS.

## Browser support

Needs **WebSerial** — Chrome or Edge (desktop). Firefox and Safari do not implement it.
