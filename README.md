# QWavey flashers

Browser-based firmware flashers for the QWavey hardware family. One repo,
one Pages site, one card grid — three devices behind it, each with its
own subdirectory.

**Live:** https://qwavey.github.io/flashers/
**Repo:** https://github.com/QWavey/flashers *(this one — Pages: `main` / root)*

## Layout

```
index.html                              — the hub (3 cards)
css/style.css   favicon.svg             — hub design tokens
watch-badusb/       ESP-Watch-BadUSB    — ESP32-S3 Touch-AMOLED 2.06" watch port
  index.html + firmware/*.bin           →  qwavey.github.io/flashers/watch-badusb/
rubberless-ducky/   Rubberless-Ducky    — Hak5 USB Rubber Ducky Mk II open firmware
  index.html + firmware.hex             →  qwavey.github.io/flashers/rubberless-ducky/
esp-s3-key/         ESP-S3-Key BadUSB   — the ESP32-S3-Dongle "USB key" BadUSB
  index.html + firmware/*.bin           →  qwavey.github.io/flashers/esp-s3-key/
```

Each subfolder is a self-contained static site (its own `index.html`,
`css/`, `js/`, and firmware image), reachable directly by URL, and linked
from the hub. Cross-links between them use relative paths, so the whole
tree is a single deploy.

## Which device → which firmware source?

The flasher subfolders here hold **only the deployable web site + image**;
the *firmware sources* live in their own repos:

| Device | Flasher (this repo) | Firmware source |
|---|---|---|
| ESP32-S3 Touch-AMOLED watch | `watch-badusb/` | [QWavey/ESP-S3-Key-BadUSB — watch port](https://github.com/QWavey/ESP-S3-Key-BadUSB) *(same firmware base, watch-specific port lives in the [`watch-badusb-project/ESP-Watch-BadUSB`](https://github.com/QWavey/ESP-S3-Key-BadUSB) directory)* |
| ESP32-S3 Key (USB-A dongle) | `esp-s3-key/`     | [QWavey/ESP-S3-Key-BadUSB](https://github.com/QWavey/ESP-S3-Key-BadUSB) |
| Hak5 USB Rubber Ducky Mk II | `rubberless-ducky/` | [QWavey/Rubberless-Ducky](https://github.com/QWavey/Rubberless-Ducky) |

The flashers themselves are generated by
[QWavey/flasher-forge](https://github.com/QWavey/flasher-forge) — a Python
GUI + tracer that turns a photo + a firmware image into a WebSerial /
WebUSB flasher project. FlasherForge is the *builder*; the sites it
outputs land here.

## History

This repo used to be just the hub, with each device linking out to a
separate repo:

- `qwavey.github.io/WebFlasher/`         (was: `QWavey/WebFlasher`)
- `qwavey.github.io/ESP-S3-Key-BadUSB/`  (was: `QWavey/ESP-S3-Key-BadUSB/docs/`)

Those old URLs still work today. The intent going forward is one deploy
per device family lives here, and the old repos either archive or drop
a `<meta http-equiv="refresh">` stub pointing at the new URL.

## Adding a new device

1. Build the flasher site with FlasherForge (`python flasher-out/build_*.py`).
2. Drop the generated tree in as a sibling of the existing ones
   (e.g. `flashers/my-new-device/`).
3. Add a card to `index.html` linking to `./my-new-device/`.
4. Commit and push — Pages redeploys on `main`.
