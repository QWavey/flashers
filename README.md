# QWavey flashers

Browser-based firmware flashers for the QWavey hardware family. The repo holds one GitHub Pages site with a card for each device, and each device has its own subfolder.

**Live:** https://qwavey.github.io/flashers/
**Repo:** https://github.com/QWavey/flashers (Pages serves the `main` branch, root folder)

## Layout

```
index.html                              - the hub (3 cards)
css/style.css   favicon.svg             - hub design tokens
watch-badusb/       ESP-Watch-BadUSB    - ESP32-S3 Touch-AMOLED 2.06" watch port
  index.html + firmware/*.bin           →  qwavey.github.io/flashers/watch-badusb/
rubberless-ducky/   Rubberless-Ducky    - Hak5 USB Rubber Ducky Mk II open firmware
  index.html + firmware.hex             →  qwavey.github.io/flashers/rubberless-ducky/
esp-s3-key/         ESP-S3-Key BadUSB   - the ESP32-S3-Dongle "USB key" BadUSB
  index.html + firmware/*.bin           →  qwavey.github.io/flashers/esp-s3-key/
```

Each subfolder is a self-contained static site with its own `index.html`, `css/`, `js/`, and firmware image. Each one can be opened directly by URL and is linked from the hub. Links between them are relative, so the whole tree deploys as one site.

## Which device goes with which firmware source?

This repo holds only the deployable web site and image for each device. The firmware sources live in their own repos:

| Device | Flasher (this repo) | Firmware source |
|---|---|---|
| ESP32-S3 Touch-AMOLED watch | `watch-badusb/` | [QWavey/ESP-Watch-BadUSB](https://github.com/QWavey/ESP-Watch-BadUSB) (port of the ESP-S3-Key firmware to the watch hardware) |
| ESP32-S3 Key (USB-A dongle) | `esp-s3-key/` | [QWavey/ESP-S3-Key-BadUSB](https://github.com/QWavey/ESP-S3-Key-BadUSB) |
| Hak5 USB Rubber Ducky Mk II | `rubberless-ducky/` | [QWavey/Rubberless-Ducky](https://github.com/QWavey/Rubberless-Ducky) |

The flashers are generated by [QWavey/flasher-forge](https://github.com/QWavey/flasher-forge), a Python GUI and tracer that turns a photo and a firmware image into a WebSerial or WebUSB flasher project. FlasherForge is the builder. The sites it outputs land in this repo.

## History

This repo used to contain only the hub. Each device linked out to its own repo:

- `qwavey.github.io/WebFlasher/` (formerly `QWavey/WebFlasher`)
- `qwavey.github.io/ESP-S3-Key-BadUSB/` (formerly `QWavey/ESP-S3-Key-BadUSB/docs/`)

Those old URLs still work. The plan is to keep one deploy per device family in this repo. The old repos will either be archived or get a `<meta http-equiv="refresh">` stub that points to the new URL.

## Adding a new device

1. Build the flasher site with FlasherForge (`python flasher-out/build_*.py`).
2. Copy the generated folder in as a sibling of the existing ones, for example `flashers/my-new-device/`.
3. Add a card to `index.html` that links to `./my-new-device/`.
4. Commit and push. Pages redeploys from `main`.
